Contributing to RepoReady

Thank you for your interest in contributing to RepoReady.

How to Contribute

1. Check existing issues or open a new issue describing the problem.
2. Explain the change you want to make.
3. Keep pull requests focused on one improvement.
4. Add or update tests when changing functionality.
5. Run the test suite before submitting your changes.

Reporting Bugs

Include steps to reproduce the bug, the expected behavior, and the actual behavior.

Code Quality

- Follow standard Python conventions.
- Use clear variable and function names.
- Keep documentation up to date.
- Avoid unnecessary dependencies.

Community

Be respectful, constructive, and open to feedback.

We appreciate useful contributions from the community.
