RepoReady

RepoReady is a beginner-friendly Python tool that checks open-source repositories for essential project files.

Features

- Checks for README.md
- Checks for a LICENSE file
- Checks for CONTRIBUTING.md
- Checks for CODE_OF_CONDUCT.md
- Checks for a tests directory
- Suggests improvements when files are missing

Requirements

- Python 3.9 or newer
- No third-party dependencies

Usage

Run the following command from the project directory:

python repoready.py .

Tests

Run the automated tests with:

python -m unittest discover -s tests
